# **App Name**: LexiGuard

## Core Features:

- User Authentication: Secure login and signup with session persistence; company accounts support multiple users.
- Dashboard Overview: Display contract stats, risk summaries, and recent activities with quick actions.
- Contract Management: Enable uploading, searching, filtering, and bulk actions for contracts (PDF, DOCX).
- Clause Analysis: Use AI to analyze clauses, highlight risks, and suggest improvements. Includes annotation and note features.
- Translation Tool: Provide a dual-pane viewer for original and translated text with glossary integration. Lets the user refine the output of a translation tool.
- Risk Scoring: Assess contract-level and clause-level risks with color-coded alerts and drill-down capabilities.
- Reporting and Analytics: Generate charts and tables for contract trends, risk distribution, and user behavior, with filtering and drill-down options.

## Style Guidelines:

- Primary color: Saturated red (#E74C3C), drawing on the concept of highlighting risk to suggest an active, urgent tone.
- Background color: Desaturated red (#FAD7D4) to maintain consistency without overwhelming the interface; complements the red tones without distracting from content.
- Accent color: Analogous orange (#F39C12) to provide visual contrast and guide user attention.
- Headline font: 'Poppins' (sans-serif) for a contemporary, geometric design; pairs effectively with PT Sans for body text.
- Body font: 'PT Sans' (sans-serif) offering a humanist touch, making long text passages more engaging.
- Use sharp, modern icons to match React's efficient and clear architecture. Aim for high contrast for easy interpretation, especially when denoting risk levels.
- Subtle, smooth transitions and animations using Anime.js to reinforce user actions and system responses (e.g., fade-ins, slides, pulses) to avoid abrupt changes and create a polished experience.
